# Smart PetFeeder App

This is the Expo mobile app for the Smart PetFeeder repository.

The app is currently a mock-only React Native prototype. It does not connect to Firebase or real hardware yet.

## Setup

```powershell
npm install
npm run start
```

## Useful Commands

```powershell
npm run android
npm run ios
npm run web
npm run lint
.\node_modules\.bin\tsc.cmd --noEmit
```
